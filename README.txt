HAPPY 18TEEN BIRTHDAY WEBSITE
==============================

FILES
- index.html, style.css, script.js
- photo-1.jpg through photo-5.jpg (your uploaded photos, included in the root)
All files are in ONE folder; there is no images folder.

PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.

EDIT TEXT
Open index.html in any text editor and edit the text you want.
The long letter is inside the section with id="letter".

CHANGE PHOTOS
Replace photo-1.jpg ... photo-5.jpg with your own images.
Keep exactly the same filenames so the website can find them.
Keep all files together in the same folder.

PUBLISH
Upload all the extracted files together to Netlify Drop or a GitHub Pages repository.
Google Fonts need an internet connection; the rest of the site works locally.
